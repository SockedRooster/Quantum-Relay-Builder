Quantum Relay Builder v2.3.1 — Sprint 6.3.1 Structural Truss Upgrade

Install the add-on ZIP from Blender Preferences > Add-ons > Install from Disk.
Restart Blender after replacing an earlier build so cached Python modules are cleared.

- 20% reflector scale applied to stock presets
- Wider/flatter hub proportions
