# Quantum Relay Builder

Procedural Blender tooling for the Quantum Relay KSP asset family.

## Current release

v1.3.0 — Sprint 5.1 Foundation Refactor

## Features

- Large-scale seven-panel QR-100 baseline
- Parametric hex reflector generation
- Curvature and automatic panel aiming
- Layered support hub
- Radial support arms
- Centralised versioning
- Centralised object naming
- Semantic part registry with duplicate-name protection

## Install

Install the release ZIP through Blender:

`Edit > Preferences > Add-ons > Install from Disk`

Then open the `Quantum Relay` sidebar tab in the 3D Viewport.
