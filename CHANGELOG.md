# Changelog

## 2.0.0 — Sprint 6.0

- Added a reusable BMesh procedural mesh framework.
- Added operator-free object creation in `mesh/core.py`.
- Added reusable prism, plate, cylinder and annular-segment generators.
- Added profile-extruded beams with automatic three-dimensional orientation.
- Added box, diamond and hexagonal structural profiles.
- Migrated the legacy prism compatibility function to the BMesh engine.
- Migrated cross braces to profile-based beam generation.
- Added QR-100, QR-250 and QR-500 relay-family presets.
- Added topology statistics to build completion reports.
- Updated the UI for preset selection and brace profiles.
- Advanced the add-on version to 2.0.0.

## 1.3.2 — Sprint 5.3

- Added arm-to-ring mounting blocks and upper clamps.
- Added paired triangular reinforcement gussets.
- Added optional polygonal cross-bracing.
- Added independent Structure Detail controls.
